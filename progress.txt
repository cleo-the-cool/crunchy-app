## Codebase Patterns
- Use `npm install --legacy-peer-deps` for dependency installation (peer dep conflicts)
- Run tsc via `node_modules/typescript/bin/tsc --noEmit` (symlink may break)
- NativeWind uses `className` prop on RN components for Tailwind styling
- Custom colors: sage (#8B9E7C), peach (#F4A574), cream (#FAF8F5), dark (#2D2D2D)
- Path alias `@/` maps to project root in tsconfig
- Expo Router uses file-based routing in `app/` directory
- Tab navigation configured in `app/(tabs)/_layout.tsx`
- Tailwind config includes `./components/**/*.{js,jsx,ts,tsx}` in content paths
- Shared components exported from `@/components` barrel file (index.ts)
- Use inline `style` prop for shadows on Card (RN doesn't support CSS box-shadow)
- Rating colors: clean (#4CAF50), caution (#FFC107), avoid (#F44336)
- Import `SharedValue` type directly from `react-native-reanimated` (not `Animated.SharedValue`)
- Screens outside tabs go directly in `app/` directory (e.g., `app/welcome.tsx`, `app/onboarding.tsx`)
- Use `react-native-view-shot` + `expo-sharing` for shareable card images
- ScrollView with `scrollEnabled={false}` + programmatic `scrollTo` for controlled carousels
