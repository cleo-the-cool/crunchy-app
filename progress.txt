## Codebase Patterns
- Use `npm install --legacy-peer-deps` for dependency installation (peer dep conflicts)
- Run tsc via `node_modules/typescript/bin/tsc --noEmit` (symlink may break)
- NativeWind uses `className` prop on RN components for Tailwind styling
- Custom colors: sage (#8B9E7C), peach (#F4A574), cream (#FAF8F5), dark (#2D2D2D)
- Path alias `@/` maps to project root in tsconfig
- Expo Router uses file-based routing in `app/` directory
- Tab navigation configured in `app/(tabs)/_layout.tsx`
- Tailwind config includes `./components/**/*.{js,jsx,ts,tsx}` in content paths
- Shared components exported from `@/components` barrel file (index.ts)
- Use inline `style` prop for shadows on Card (RN doesn't support CSS box-shadow)
- Rating colors: clean (#4CAF50), caution (#FFC107), avoid (#F44336)
- Import `SharedValue` type directly from `react-native-reanimated` (not `Animated.SharedValue`)
- Screens outside tabs go directly in `app/` directory (e.g., `app/welcome.tsx`, `app/onboarding.tsx`)
- Use `react-native-view-shot` + `expo-sharing` for shareable card images
- ScrollView with `scrollEnabled={false}` + programmatic `scrollTo` for controlled carousels
- Auth context lives in `contexts/AuthContext.tsx`, provides `useAuth()` hook
- AuthProvider wraps the app in `app/_layout.tsx`
- Mock auth uses `@react-native-async-storage/async-storage` with key `@crunchy_auth_user`
- Protected routes: check `useSegments()` in root layout effect, redirect to `/login` if not authed and in `(tabs)`
- Use `expo-haptics` for haptic feedback: `Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium)`
- Badge component accepts optional `label` prop to override default rating text
- `expo-camera` v55 uses `CameraView` (not `Camera`), with `barcodeScannerSettings` and `onBarcodeScanned` props
- Set `onBarcodeScanned={undefined}` to pause scanning and prevent rapid re-fires
- Use `useLocalSearchParams` from expo-router to read route params in destination screens
- Mock product data in `data/products.ts`: use `findProductByBarcode()` to look up, `getDefaultProduct()` for unknown barcodes
- Product types (Product, Ingredient, Alternative, Rating, IngredientRisk) exported from `data/products.ts`
- Categories constant `CATEGORIES` and helpers `getProductsByCategory()`, `searchProducts()` exported from `data/products.ts`
- Navigate to product detail via `router.push(/scan-result?barcode=${product.barcode})` to reuse scan-result screen
- Recipe data in `data/recipes.ts`: `getRecipeById()`, `getRecipesByCategory()`, `searchRecipes()`, `filterRecipes()`
- Navigate to recipe detail via `router.push(/recipe-detail?id=${recipe.id})`, recipe list via `router.push("/recipes")`
- Products link to recipes via `diyRecipeId` field matching recipe `id` values (e.g., "recipe-001")
- Community post data in `data/community.ts`: `COMMUNITY_POSTS`, `TRENDING_HASHTAGS`, `getPostById()`, `getPostsByHashtag()`
- Create post screen at `app/create-post.tsx`, navigate via `router.push("/create-post")`
- Settings screen at `app/settings.tsx`, navigate via `router.push("/settings")`
- Profile tabs use state toggle (`activeTab`) with conditional rendering, no nested navigators
- Subscription context in `contexts/SubscriptionContext.tsx`, provides `useSubscription()` hook with `canScan`, `recordScan()`, `tier`, `isPremiumFeature()`
- Navigate to paywall via `router.push({ pathname: "/paywall", params: { reason: "scan_limit" | "premium_feature" } })`
- Supabase migrations in `supabase/migrations/` with numbered filenames; seed data in `supabase/seed.sql`
- Stable seed UUIDs: recipes=`a0000000-...`, products=`b0000000-...`, users=`c0000000-...`, posts=`d0000000-...`, comments=`e0000000-...`
- Label scan screen at `app/label-scan.tsx`, navigate via `router.push("/label-scan")` from scan.tsx label mode
- Use `{"text with apostrophe"}` JSX expression for text containing apostrophes to satisfy `react/no-unescaped-entities` lint rule
- Product scan screen at `app/product-scan.tsx`, navigate via `router.push("/product-scan")` from scan.tsx product mode
- For scan modes: barcode is inline in scan.tsx, label and product each have dedicated screens (`label-scan.tsx`, `product-scan.tsx`)
- Use `Animated.createAnimatedComponent(Pressable)` with `withSpring` scale for press animations on buttons
- `SkeletonLoader`, `CardSkeleton`, `ProductCardSkeleton` exported from `@/components` for loading states
- Screen transitions configured in root `Stack` via `animation: "slide_from_right"` in `app/_layout.tsx`
