## Codebase Patterns
- Use `--legacy-peer-deps` when installing npm packages (peer dep conflicts with expo-router's radix-ui deps)
- Run TypeScript check with `node node_modules/typescript/lib/tsc.js --noEmit` (npx tsc symlink is broken)
- Verify builds with `npx expo export --platform ios --output-dir /tmp/crunchy-export`
- NativeWind v4 uses `nativewind/preset` in tailwind.config.js and `nativewind/babel` preset in babel.config.js
- Metro config needs `withNativeWind` wrapper from `nativewind/metro`
- Import `../global.css` in app/_layout.tsx for NativeWind to work
- Design system colors: sage=#8B9E7C, peach=#F4A574, cream=#FAF8F5, dark=#2D2D2D
- Expo SDK 55 with expo-router v55, React 19, React Native 0.83
